# Survivor.io DMG Calculator v2

A static, GitHub Pages-compatible reference/calculator built from the images supplied in the conversation.

## Included
- Mobile-friendly Crit Rate / Crit Damage estimator
- Equipment gallery and Chaos Fusion milestone reference
- Survivor portrait gallery
- Xeno Pet gallery
- Mount gallery
- Turf LV.1-LV.6 reference
- Original supplied reference sheets preserved in `assets/reference-sheets/`
- Cropped icon assets in `assets/icons/`

## Deploy
1. Upload the contents of this folder to the GitHub repository.
2. Keep `index.html` at repository root.
3. In GitHub: Settings → Pages → Deploy from branch → `main` / root.
4. Open the resulting GitHub Pages URL.

No build system or server is required.

## Important
The source screenshots contain very dense game data. Where OCR could not reliably recover exact wording, the site preserves the original image rather than inventing values.
